## 审查重点

1. 未登录不请求私人列表；失败不能显示成空列表。
2. 手机切换与诊断抽屉不得丢失输入、对话滚动或生成状态。
3. 系统深色时弹窗、表格、输入与正文需同色系且可读。
4. 长 ID／提示词／应用名不得挤掉操作按钮或造成整页横向溢出。
5. 请求快速切换与重试、删除确认和角色权限应保留原业务边界。
