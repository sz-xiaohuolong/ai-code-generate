# P0 目标设计

状态：IMPLEMENTED；Phase：p0-reliability。2026-10-18 已按冻结需求实施，验收范围见 [VERIFICATION.md](VERIFICATION.md)。

## 任务与所有权

使用现有 StringRedisTemplate 与 Lua，将请求映射、应用租约、初始任务和最近任务索引一次认领。任务 UUID 与请求 UUID 分离，绑定用户、应用和规范化输入摘要；任务记录保留 24 小时。应用租约短期续期，所有释放、快照更新、最终发布均校验任务所有者。Redis 故障时拒绝启动，执行中停止发布，不离线放行。

后台虚拟线程拥有整个执行生命周期。SSE 只轮询并展示聚合快照，没有订阅者时仍运行。任务记录包含状态、阶段、聚合输出、流程步骤、诊断摘要、修复次数及真实模型用量；快照定期保存，终态立即保存。停止接口设置 STOPPING；执行上下文取消响应式订阅、禁止后续文件操作、清理进程树并等待文件操作退出，随后记录终态并按所有者释放。租约失效且没有本地执行者的记录标记中断。

新增 POST /app/generation/tasks、GET /app/generation/tasks/{taskId}、GET /app/generation/tasks/current?appId、GET /app/generation/tasks/{taskId}/events、POST /app/generation/tasks/{taskId}/stop。全部验证登录与应用所有权。旧 SSE 与两个演示入口适配至该服务；生成请求须提供稳定 clientRequestId，错误明确返回。SSE 发送 task-snapshot，首包即当前快照，终态后结束；客户端自动恢复仅订阅，不重新创建任务。

## 工作目录与成功版本

每个任务使用 tmp/generation_tasks/<appId>/<taskId>，从上次成功源码复制，排除 node_modules／dist／链接。AppChatMemoryId 携带本轮 taskId，工具从执行上下文取得根目录，跨异步线程不依赖 ThreadLocal。HTML／多文件保存器也支持显式本轮目录。

通过交付验证后，当前工作目录成为不可再修改的成功版本，以 Lua 在仍拥有应用租约时切换 Redis 成功指针；旧版本继续保留。静态预览先重定向到 `v_<taskId>_<type>_<appId>` 固定版本地址，HTML 及相对资源保持同版；仅已发布版本允许访问。兼容旧 Vue `dist/` 前缀。下载及部署解析成功指针，兼容未迁移的旧生成目录。成功发布后沿用异步封面截图，失败和取消不触发封面更新。已失去所有权的旧任务只能写自己的草稿，不能切换指针。部署消费成功 dist；不重新构建或覆盖成功源码。

## 交付闭环

VueProjectBuilder 用 ProcessBuilder 执行固定 npm 参数，分开持续消费 stdout／stderr，限长保存、按退出码和日志分类；总剩余预算约束每步超时，取消／超时清理进程树。package.json／lockfile 指纹未变且 node_modules 可用时跳过安装。

VueDeliveryService 为标准与工作流共享：构建 → 预览检查 → 成功；可修复诊断 → 最多两轮模型局部修复 → 再验证。相同诊断重复或环境故障停止。修复使用临时记忆，包含诊断、必要文件索引和当前代码按需读取，不污染正式聊天。工具调用轮次与总截止时间约束全部模型调用。工作流图片规划、质检等结构化调用也通过可取消的流式模型适配，统一记录实际 usage；模型未报告时保留缺失语义。浏览器以临时本地 HTTP 服务访问任务产物，检查入口／资源／挂载与控制台严重错误，验证完成关闭服务和浏览器。

## 兼容、权限与恢复

不新增数据库 Schema，不改变应用模式与生成类型规则。正式历史只记录一次原始输入及最终成功／失败／取消结果。认领任务时分配两个稳定 Snowflake 主键；终态、成功指针与待记历史在同一 Lua 中提交。独立调度器用数据库事务及幂等插入补记两条历史，核对归属和内容后清除待记记录；待记内容持续保留至补记成功，不随任务明细过期。下一轮使用同应用历史前确认补记已恢复。快照按稳定历史主键合并前端记录，避免毫秒时间被数据库截断至秒后重复展示。新接口限应用所有者；聚合内容不返回宿主路径或 Secret。依赖原有 Redis、本机 Node 和浏览器设施；本轮工作目录隔离不宣称容器级恶意代码沙箱。进程重启恢复到明确中断；Redis 数据应按现有运维方式持久化，指针与版本目录须共同备份。

回退代码时保留新 Redis 键和版本目录，预览恢复旧目录仅能读取回退前的旧版本；通过向前修复恢复成功指针，禁止自动删除成功版本。后续只有在引用和恢复边界明确时才增加清理策略。
