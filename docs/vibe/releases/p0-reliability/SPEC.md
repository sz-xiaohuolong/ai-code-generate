# P0：生成与 Vue 交付可靠性

| 范围 | 冻结行为 | 验收入口 |
|---|---|---|
| 生成任务 | 幂等、互斥、后台执行、恢复和显式停止 | 任务服务／接口／浏览器 |
| Vue 交付 | 构建诊断、最多两轮修复、预览检查、成功版本保留 | 构建／交付／版本测试 |
| 边界 | 一 Phase；任务默认 20 分钟；不纳入上下文压缩 | 下列 REQ／AC |

需求状态：FROZEN。批准依据：2026-10-18 用户 Q1～Q7 全部同意，并要求直接设计、实施和同步远程。

## 已确认的行为

| 编号 | 行为与验收条件 |
|---|---|
| REQ-01 | 标准和工作流共用任务入口；同一用户的相同 clientRequestId 和相同应用、输入复用一个任务，重复 ID 不同内容拒绝；重复提交不得重新调用生成或重复写历史。幂等与任务明细保留 24 小时。 |
| REQ-02 | 同一应用只有一个修改任务；不同请求立即返回忙碌，无排队。锁覆盖生成、质检、修复、构建、验证与发布；按所有者续期和释放，丢失所有权的旧任务禁止发布。 |
| REQ-03 | 页面断线、刷新、离开不取消后台任务；恢复状态、当前步骤、已有输出并订阅后续进度，终态提供完整结果；不要求补播逐条旧事件。 |
| REQ-04 | 显式停止先进入 STOPPING，停止模型流、文件操作和构建进程后才进入 CANCELLED、释放应用；不自动续跑。超时同样清理，终态明确区分失败／取消／超时／服务中断。 |
| REQ-05 | 默认总预算 20 分钟，覆盖生成、质检、安装、构建、验证及修复；最多两轮构建修复；相同诊断持续出现提前停止。记录模型调用次数及供应商实际返回的 token usage，缺失用量不得填成真实零值；首期不增加新付费供应商或金额扣款系统。 |
| REQ-06 | 本轮在专属工作目录修改；两种模式均以通过交付检查为成功。新成功版本才切换代码、预览和下载来源；失败／取消不覆盖最近成功版本。首次失败明确无可用版本；部署读取成功版本，不读取正在修改的草稿。 |
| REQ-07 | Vue 构建返回阶段、退出码、有限长度 stdout／stderr、超时和错误分类；源代码／依赖声明错误可修复，网络、认证、环境、超时、取消不触发盲目代码修复。 |
| REQ-08 | 两种模式共享同一 Vue 修复能力；根据真实诊断按需读文件和局部修改，修复后重新构建，避免无变化时重复安装；标准模式显示简要状态，工作流显示真实步骤及重试次数。 |
| REQ-09 | 发布前验证 HTML 入口及资源、Vue 挂载与浏览器运行错误；失败不会展示本轮成功。文件工具限制在本轮应用根目录内，拒绝绝对路径、越界和符号链接绕过，局部替换要求唯一匹配。 |
| REQ-10 | 启动、状态、订阅、停止仅限应用所有者；断线重连不触发新生成。应用服务进程重启后，租约失效的未完成任务标记 INTERRUPTED，不自动重放模型；新请求可以显式重试。 |

## 状态与兼容

任务状态为 STARTING → RUNNING → SUCCEEDED／FAILED／TIMED_OUT；主动停止经过 STOPPING → CANCELLED；失去执行进程或所有权进入 INTERRUPTED。任何终态不允许再次运行。任务状态持久化使用现有 Redis；正式聊天沿用数据库，不新增业务表或迁移。成功版本指针不使用任务明细的 24 小时过期时间。

模式按应用固定、创建入口的偏好只影响新应用；后续对话保持代码类型，这些已发布行为继续有效。已有成功目录作为首次版本来源兼容。正式和工作流演示生成入口统一经过任务服务。新增任务 API 与订阅协议在设计中说明，旧生成 SSE 作为兼容适配器，亦需稳定 clientRequestId 才能启动任务。

## 不在范围内

三层上下文压缩、任务排队、服务重启后自动续跑、逐事件回放、版本管理产品界面、自动部署、完整容器平台和供应商计费精确一次保证。

## 验证接缝

- 任务仓储：真实 Redis 原子认领、幂等冲突、租约续期、错误所有者释放与发布拦截。
- 任务执行：并发请求、断开订阅仍完成、重新订阅、取消、总超时、异常收尾及一次历史记录。
- 文件与版本：真实临时目录，旧版本完整性、成功切换、越界／符号链接、重复替换与取消后的写入。
- 构建与交付：真实 Node 子进程、输出限长、错误分类、子进程清理、修复次数与错误不变熔断、浏览器检查。
- 接口／UI：所有者校验、重复 ID、后台恢复、主动停止、标准／工作流状态、失败保留预览；外部模型固定少量真实样例，其他故障由可控模型接缝重现。
